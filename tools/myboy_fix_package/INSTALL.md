# 록맨 에그제 2 V0.9.2 선택창·PET 메뉴 수정 패치

일본판 Rev 1 전용 BPS 패치입니다. 원본 ROM과 저장 파일은 포함하지 않습니다.
V0.9의 번역과 폰트를 유지하면서 교실 선택창의 줄바꿈/선택지 겹침과 PET 첫
메뉴의 일본어 그래픽 라벨을 수정했습니다. My Boy! 기기에서 확인할 수 있는 후보입니다.

## 적용

1. ZIP을 새 폴더에 모두 풉니다.
2. 깨끗한 일본판 Rev 1 ROM을 `APPLY_PATCH.cmd`에 끌어다 놓습니다.
3. `SUCCESS`가 표시되면 `Rockman_EXE2_Rev1_KR_V0.9.1_MyBoyFix.gba`를
   휴대폰으로 옮겨 My Boy!에서 새로 실행합니다.
4. START로 PET 메뉴를 열어 9개 한글 항목을 확인하고, 칩 폴더·서브칩 진입 및
   B 버튼 복귀를 확인합니다. 교실에서는 야이토의 선택 질문이 세 줄 안에 표시되는지 확인합니다.

원본 SHA-256:
`1afe35e1d00099d62cbddad43c2be3f0f3c3f0f333e8df54456076cb2df6a6b8`

이미 V0.9가 적용된 ROM에 덧붙이는 패치가 아닙니다. 적용기는 원본·패치·결과
해시를 검사하며 기존 출력 파일은 덮어쓰지 않습니다. 결과 해시는 manifest.json에 있습니다.

## 기존 진행 이어 하기

기존 게임 내 저장 파일(.sav)을 먼저 백업합니다. 새 ROM의 파일명에 맞춘
복사본으로 이어 할 수 있습니다. 저장 데이터 형식은 변경하지 않았습니다.
에뮬레이터의 이전 즉시 저장 상태(.ss1/.ss2 등)는 사용하지 마세요.
그 상태에는 수정 전 메뉴 코드와 메모리가 남아 있을 수 있습니다.
새 ROM을 완전히 다시 부팅하고 타이틀 화면의 이어하기로 시작하세요.

## 검증 범위

원본에서 다시 빌드했으며, 한글 메뉴 라벨 162개와 원문 라벨 162개를 실제
ARMv4T 출력 코드로 실행해 글꼴·종료·버퍼·스택을 확인했습니다. PET 그래픽
타일 4개 맵의 로더·VRAM·BG0 소비 경로와 선택창 제어 구조도 정적으로 확인했습니다.
음소거 Mesen 메뉴 조작 기록은 검증 요약에 포함됩니다.
My Boy! 앱 자체의 수정본 실행은 아직 기기 확인 전입니다.
전체 게임 QA와 V0.9에 기록된 미번역·특수창 검수는 계속 남아 있습니다.

Floating IPS v198 실행 파일과 GPL 라이선스 및 해당 버전 소스를 동봉했습니다.
