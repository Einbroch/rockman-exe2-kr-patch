# EXE2 Rev 1 한국어 패치 V0.9.19 (시험용)

원본 일본판 Rev 1 ROM에 동봉된 BPS 패치를 적용하세요(`APPLY_PATCH.cmd` 또는
동봉된 flips). 이전 패치 ROM에는 덧씌우지 마세요.

## 선택창이 원문 배치대로 나옵니다 (262건)

넷 상인의 "저는 넷 상인... / 좋은 물건이 있습니다" 선택창처럼, 질문과
선택지가 한 줄로 뭉쳐 창 밖으로 밀리던 문제를 고쳤습니다.

원인: 번역 초안의 문법 변환기가 **질문 안쪽 줄바꿈을 선택지 경계로
먹었습니다**. 그래서 질문 둘째 줄이 첫 선택지 칸으로 들어가고 선택지가
한 칸씩 밀렸으며, 질문 끝 줄바꿈도 사라졌습니다. 넷 상인 대사는 한 줄이
34칸이었습니다(창은 21칸).

- **규칙 수정 (224건)**: 선택지가 있는 대사는 원문과 같은 방식으로 선택지
  경계를 찾고(질문 안쪽 줄 수 기준), 원문의 선택지 끝 줄바꿈·공백을
  유지합니다.
- **칸 단위 재작성 (38건)**: 초안 자체가 원문 칸 구조와 어긋난 것들입니다.
  퀴즈 문제 5건은 질문과 선택지가 서로 다른 페이지인데 초안이 한 페이지로
  적어 질문 칸이 선택지까지 삼키고(6줄) 선택지 칸은 비어 있었습니다.

## 대사 중 찍히는 이름 때문에 창을 넘던 13건

기존 조판 검사는 대사 중간에 찍히는 아이템·칩 이름의 폭을 0으로 쟀습니다.
실제 이름 폭으로 재니 13건이 창을 넘고 있었습니다. 예:

- "현재 SS 라이선스 시험을 실시하고 있습니다" 한 줄 24칸
- "...그럼 약속대로서브 라이선스를 드리죠" (띄어쓰기도 빠져 있었음)

원문처럼 이름 뒤 줄바꿈과 공백을 되살렸습니다. 레트로 칩 트레이더
문구가 한 칸씩 밀려 4줄이 되던 것도 같이 고쳤습니다.

## 빌드 검사 확장

이제 **번역된 대사 8,290건 전부**를 선택지 커서 칸, 선택 뒤 창 비우기,
실제 이름 폭까지 넣어 재고, 원문이 그리는 창을 넘거나 선택지가 비거나
늘어나면 빌드를 멈춥니다. 창을 넘는 대사는 실기에서 멈춤으로 이어지는
부류입니다. 기존 "비표준 창" 기록은 94건에서 4건이 됐고, 남은 4건은
옛 측정이 선택 뒤 창 비우기를 몰라 생긴 착오로 새 검사는 통과합니다.

## 남은 것

- **칩 선택 화면 OK/ADD 안내문, 전투 결과 "딜리트 타임/버스팅 레벨"**:
  문자열이 아니라 그림(타일)으로 그려지는 것으로 보여 조사 중입니다.
  "딜리트 타임"은 문자열 쪽에는 이미 번역돼 있는데 화면은 그것을 읽지
  않습니다.
- 대사 중 이름 앞 띄어쓰기 누락 약 230건 (창은 넘지 않음).
- 대형 갭에 묻힌 꼬리 대사 2줄.
- 전체 게임 완주 QA.

## 검증

정적 무결성 검사와 표 내용 검사를 통과했습니다. 아카이브 393개, 번역
엔트리 8,290개, 창 검사 위반 0건. 넷 상인·퀴즈·"약속대로"·폭포 대사를
빌드된 ROM에서 직접 해독해 원문 배치대로 들어간 것을 확인했습니다.
