# EXE2 Rev 1 한국어 패치 V0.9.15 (시험용)

원본 일본판 Rev 1 ROM에 BPS 또는 xdelta를 적용하세요. 이전 패치 ROM에는
덧씌우지 마세요.

## 후속 스크립트 번역 — 2건 → 204건

아카이브에는 경계표가 선언한 길이 **뒤로 이어지는 스크립트**가 있습니다.
게임은 그 바이트를 그대로 읽어 씁니다. 지금까지 패치는 그걸 원본 그대로
보존만 했기 때문에 화면에 일본어로 나왔습니다.

튜토리얼 배틀에서 보이던 일본어가 바로 이것이었습니다.

```
원본 0x07969EB (00/350 꼬리)
  チップデータは きほんてきに、1ターンに 1つしか おくれないけど、
  キャノンとキャノン みたいに おなじ チップデータなら
  いっしょに えらぶことが できるの
```

**204개를 번역했습니다.** 일본어 4,571자 분량입니다. 주요 구간:

- 튜토리얼 배틀 칩 설명 (`00/350`, `00/351`)
- A 라이선스 시험 안내 전체 (`00/210`, `00/213`)
- 나이트맨·포르테·고스펠 보스 대사 (`00/269`, `00/320`, `00/337`)
- 엔딩 내레이션 (`00/334`)
- 아메로파 여정, 케로 리포트, 각 지역 이동 대사 다수

## 어떻게 했는지

`tools/continuation_translation_workfile.py` 를 새로 만들었습니다.

`dump` 은 각 꼬리의 **따옴표 안 리터럴만** 뽑아 작업 파일로 내놓고, `build`
는 번역을 되받아 TPL 을 다시 씁니다. **제어 명령·순서·리터럴 개수는 원본
그대로** 두므로 다시 컴파일한 꼬리가 같은 모양을 유지합니다.

넣기 전에 두 가지를 검사합니다.

- **창 규격** — 페이지 단위로 21칸×3줄을 넘는지. 원본이 창 안에 들어가는
  경우만 위반으로 셉니다.
- **글자 생존** — TextPet 은 표에 없는 글자를 소리 없이 버립니다. 빌드가
  작성한 리터럴이 컴파일 후에도 순서대로 남아 있는지 대조합니다.

추출 도구(`extract_physical_continuation_tpl.py`)도 지금 빌드 모듈에 맞게
고쳤습니다. 512바이트를 넘는 7개는 **스크립트 꼬리가 아니라** 다음
카탈로그 아카이브까지의 빈 구간이고 그 안에 카탈로그에 없는 아카이브가
들어 있어, 하나의 메시지로 감싸지 않고 원본 그대로 통과시킵니다.

## 남은 것

- 후속 스크립트 21개는 원문 그대로입니다(위 7개 덩어리와 제어만 있는 것들).
- 선택창 조판 — 질문과 선택지가 한 줄에 겹칩니다. 규격 미확정 창의 넘침
  94건에 들어 있습니다.
- 동적 필드(`printItem`/`printChip`) 뒤 조사와 띄어쓰기 — 「A 라이선스을」
  처럼 받침에 안 맞는 조사와 붙어 나오는 자리가 있습니다.
- 전투 결과 화면 일본어 — 카탈로그 밖 사본을 읽는 것으로 보입니다.
- 전체 게임 완주 QA 미완료.

## 검증

정적 무결성 검사와 표 내용 검사를 통과했습니다. 표준 창 위반 0건.
후속 스크립트 224개(374,209바이트) 중 204개를 재컴파일했고 나머지는
