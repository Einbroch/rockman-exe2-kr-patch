록맨 에그제 2 일본판 Rev 1 한글 패치 - 에뮬레이터 테스트판 (2026-09-05)

중요: 미완성 테스트판입니다. 완성 한글판 또는 정식 배포판으로 안내하지 마세요.
원본 ROM, 패치된 ROM, 저장 파일은 이 압축파일에 포함하지 않습니다.

[Windows 적용 방법]
1. ZIP을 폴더에 완전히 압축 해제합니다.
2. 본인이 보유한 깨끗한 일본판 Rev 1 .gba를 APPLY_PATCH.cmd 위로 끌어다 놓습니다.
   또는 APPLY_PATCH.cmd를 더블클릭하고 원본 ROM의 전체 경로를 입력합니다.
3. SUCCESS가 표시되면 같은 폴더에 Rockman_EXE2_Rev1_KR_TEST.gba가 생성됩니다.
4. mGBA에서 생성된 ROM을 열고, 오디오를 음소거한 상태로 테스트합니다.
   상태 자동 불러오기는 끄고 새로 부팅하세요.

원본 및 출력의 SHA-256과 크기, 패치 및 패처의 SHA-256을 확인합니다.
원본과 저장 파일은 변경하지 않으며 기존 출력 파일도 덮어쓰지 않습니다.
오래된 한글 ROM이나 이전 테스트 ROM 위에 중복 적용하지 마세요.

[다른 환경]
EXE2_Rev1_KR_TEST.bps를 BPS 지원 패처로 원본 ROM에 적용한 뒤 생성된 ROM을 엽니다.
동봉한 Floating IPS의 Apply Patch 버튼으로도 적용할 수 있습니다.
Floating IPS 원본 프로젝트: https://github.com/Sir-Walrus/Flips
다른 패처를 사용하면 아래 원본/결과 SHA-256을 직접 확인하세요.

[포함 내용과 한계]
- 정식 번역 엔트리 7,607개, 한글 폰트, raw 후속 스크립트 보존 수정.
- PET 책장 소년 선택창 수정, 일반 대화 340개 줄바꿈 수정.
- 번역은 검수 전 초안이며 오역/미번역/표시 문제가 남아 있을 수 있습니다.
- 3줄 용량 등으로 보류된 일반 대화 54페이지는 아직 수정하지 않았습니다.
- 특수 창, 변수 삽입, 미확인 제어, 다른 선택창은 추가 검증이 필요합니다.
- 참조 경로가 미해결인 00/357의 95개 엔트리는 미적용입니다.
- raw 후속 영역 중 157개는 원문 보존 상태입니다.
- 일부 대화 및 PET 선택창은 음소거 Mesen 렌더러 주입 테스트를 통과했습니다.
  자연스러운 맵 진입, 모든 변경 대사의 개별 재생, mGBA 전체 게임 검증은 미완료입니다.
- 이 패키지 적용 결과는 위 검증 ROM과 바이트 단위로 동일합니다.

[저장 데이터]
기존 .sav는 반드시 백업하세요. 이 패키지는 저장 데이터를 옮기거나 변경하지 않습니다.
이전 ROM의 .ss1/.ss2 상태 저장을 불러오면 예전 대사 RAM이 복원될 수 있으므로 사용하지 마세요.
게임 내 .sav 호환성을 전체 진행 구간에서 검증한 것은 아닙니다.
