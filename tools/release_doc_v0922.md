# EXE2 Rev 1 한국어 패치 V0.9.22 (시험용)

원본 일본판 Rev 1 ROM에 동봉된 BPS 패치를 적용하세요(`APPLY_PATCH.cmd` 또는
동봉된 flips). 이전 패치 ROM에는 덧씌우지 마세요.

## 전투 결과 창 한글화

전투가 끝나면 나오는 결과 창의 라벨은 문자열이 아니라 **그림**이었습니다.
같은 글자("デリートタイム")가 대사 아카이브에도 있어 그쪽은 이미 번역돼
있었지만, 결과 창은 그것을 읽지 않고 창 전용 타일 그림을 씁니다.

결과 창은 세 종류이고 모두 한글로 바꿨습니다.

| 창 | 원문 | 한글 |
|---|---|---|
| 일반 바이러스 배틀 | デリートタイム / バスティングレベル | 딜리트 타임 / 버스팅 레벨 |
| 넷배틀 WINNER | デリートタイム / バスティングレベル | 딜리트 타임 / 버스팅 레벨 |
| 넷배틀 LOSER | チップデータをロストしました… | 칩 데이터를 잃었습니다... |

### 어떻게 바꿨나

각 창은 전용 타일 묶음과 24×17 타일 배치표를 씁니다(둘 다 압축 없음).
원본은 두 라벨이 글자 아랫부분 타일 몇 개를 **공유**하고 있어 한 칸씩
고쳐 그리면 다른 라벨이 깨집니다. 그래서 라벨 칸만 쓰던 타일을 모두 빈
자리로 확보한 뒤, 한글 라벨을 띠 단위로 새로 그려 잘라 넣고 배치표를
다시 연결했습니다. 라벨 밖의 창 모양은 픽셀 단위로 원본과 같은지 확인합니다.

글자는 패치의 한글 글꼴을 쓰고, 원본처럼 막대 밖으로 나온 부분에 어두운
테두리와 그림자를 넣었습니다.

일반 배틀 결과 창은 에뮬레이터에서 실제 결과 화면으로 확인했습니다.
WINNER/LOSER 창은 넷배틀에서만 나와서 ROM 데이터로 그려 확인했습니다.
