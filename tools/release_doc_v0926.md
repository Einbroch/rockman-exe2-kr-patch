# EXE2 Rev 1 한국어 패치 V0.9.26 (시험용)

원본 일본판 Rev 1 ROM에 동봉된 BPS 패치를 적용하세요(`APPLY_PATCH.cmd` 또는
동봉된 flips). 이전 패치 ROM에는 덧씌우지 마세요.

## 고친 것: 대사 속 띄어쓰기·줄바꿈

대사 중간에 이름을 찍거나 잠깐 멈추는 자리에서, 번역문에 적어 둔 공백이나
줄바꿈이 빌드 과정에서 지워지고 있었습니다. 대사 194개를 고쳤습니다.

### 이름 앞뒤 (37곳)

- 정말이네、서브 라이선스를 → 정말이네、 서브 라이선스를
- 오~서브 라이선스시험을 보고 있구나. → 오~ 서브 라이선스 / 시험을 보고 있구나.
- 열려면전뇌 열쇠가 필요하다! → 열려면 / 전뇌 열쇠가 필요하다!

### 잠깐 멈추는 자리 (186곳)

- 분하지만...자・극・적・이・야. → 분하지만... 자・극・적・이・야.
- 하지만!넷토를 → 하지만! 넷토를
- 뉴스는 살아 있어!...라니、 → 뉴스는 살아 있어! ...라니、

점을 하나씩 찍으며 멈추는 말줄임("・・・")이나 말 더듬기("뭐・뭐・뭐라고")는
원문처럼 붙여 둡니다. 멈추는 자리에서 줄을 바꿀지는 원문을 따릅니다.

### 원문이 줄바꿈만 두는 자리 (10곳)

- 장작이 필요하다고~? 뚝딱뚝딱뚝딱뚝딱! → 장작이 필요하다고~? / 뚝딱뚝딱 뚝딱뚝딱! / 이얏~!!

### 함께 다듬은 대사

- 라이선스 시험관: 클리어 보상은 [이름]입니다. (원문처럼 3줄)
- 아! 넷토! 나 또 / 칼을 두고 왔나 봐! (원문 줄바꿈 위치)
- 이걸로 못 해내면 남자가 아니지. (창에 들어가도록 줄임)

## 검증

- 정적 무결성 검사와 표 내용 검사를 통과했습니다. 모든 대사가 창(21칸×3줄)에
  들어가는지도 빌드가 검사합니다.
- V0.9.25와 비교해, 바뀐 대사는 모두 공백·줄바꿈만 다르고 명령은 그대로입니다.
  예외는 위에서 줄인 대사 한 줄입니다.
- 새 검사 도구가 이름·멈춤 자리 3,425곳을 대조합니다. V0.9.25에서는 186개
  대사에서 손실을 잡고, V0.9.26에서는 0건입니다.
- 에뮬레이터(Mesen)에서 대사 다섯 개를 실제 화면으로 확인했습니다.
