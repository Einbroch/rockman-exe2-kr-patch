# EXE2 Rev 1 한국어 패치 V0.9.24 (시험용)

원본 일본판 Rev 1 ROM에 동봉된 BPS 패치를 적용하세요(`APPLY_PATCH.cmd` 또는
동봉된 flips). 이전 패치 ROM에는 덧씌우지 마세요.

## 남아 있던 일본어 정리

### 게시판 제목 그림

게시판 화면 위쪽 제목은 글자가 아니라 그림(타일)입니다.

| 원문 | 한글 |
|---|---|
| 掲示板 | 게시판 |
| 依頼 掲示板 | 의뢰 게시판 |

원본처럼 흰 글자에 회색 테두리를 둘러 띠 위에 그렸습니다. 이 타일은 게시판
제목 두 줄만 쓰는 것을 확인하고 그 자리에서 다시 그렸습니다.

### P.A 등 256번 이후 칩 이름 (48개)

칩 이름은 표 두 개로 나뉘어 있었고, 256번 이후(프로그램 어드밴스 등)를 담은
두 번째 표가 번역되지 않은 상태였습니다. 전투 중 P.A 발동, 라이브러리,
대사에 찍히는 칩 이름이 이 표를 씁니다.

예: ファイターソード → 파이터소드, ゼータキャノン1 → 제타캐논1,
ドリームソード1 → 드림소드1, カースアンガー → 커스앵거, ダークメシア → 다크메시아

### 대사 뒤에 다른 데이터가 붙어 있던 꼬리 대사 4줄

대사 바로 뒤에 그림·맵 같은 다른 데이터가 이어 붙어 있어 지금까지 번역하지
못하던 줄입니다. 스크립트가 끝나는 지점을 찾아 그 부분만 번역해 넣었습니다.

- 「엘리베이터」의 전자파 제어 프로그램이다 / 여기는 이미 정상으로 돌아와 있다
- 243호실
- 더 이상 들 수 없습니다
- 이제 가방에는 칩이 10장도 없어

## 검증

정적 무결성 검사와 표 내용 검사를 통과했습니다. 표 내용 검사에 "두 칩 이름표
모두 새 위치를 가리키고 일본어 이름이 하나도 없는지"를 새로 넣었습니다.
V0.9.23과 비교해 대사 아카이브 내용은 바뀌지 않았습니다.

에뮬레이터(Mesen)에서 게시판 제목("게시판", "의뢰 게시판")과 대사에 찍히는
256번 칩 이름("파이터소드")을 확인했습니다. 꼬리 대사 4줄은 빌드 검사로만
확인했습니다.
