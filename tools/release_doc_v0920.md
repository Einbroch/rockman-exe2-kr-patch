# EXE2 Rev 1 한국어 패치 V0.9.20 (시험용)

원본 일본판 Rev 1 ROM에 동봉된 BPS 패치를 적용하세요(`APPLY_PATCH.cmd` 또는
동봉된 flips). 이전 패치 ROM에는 덧씌우지 마세요.

## 칩 선택 화면 OK·ADD 안내창을 한글로

커스텀 화면에서 커서를 OK나 ADD에 올리면 왼쪽 창에 나오는 안내는 문자열이
아니라 **그림**입니다(칩 그림이 들어가는 64×56 자리에 압축 없이 저장된 그림
3장). 같은 크기·같은 팔레트로 제자리에서 다시 그렸습니다. 영어 제목과
오른쪽 아래 장식은 그대로 두었습니다.

| 그림 | 원문 | 한글 |
|---|---|---|
| ADDITIONAL CHIP DATA | えらんだチップをすてて その まいすうぶん フォルダオープン! | 칩을 버린 만큼 / 폴더 오픈! |
| CHIP DATA TRANSMISSION | チップデータを 送信します | 칩 데이터를 / 전송합니다 |
| NO DATA SELECTED | チップが えらばれて いません | 칩이 선택되지 / 않았습니다 |

ADD 그림은 원래 일본어 마지막 글자가 모서리 장식 위에 겹쳐 있었는데, 장식이
같은 다른 그림을 기준으로 겹친 15픽셀을 원래 장식으로 되돌렸습니다.
에뮬레이터 칩 선택 화면에서 세 가지 상태 모두 확인했습니다.

## V0.9.19에서 이어지는 것

- 선택창 262건을 원문 배치로 복구 (넷 상인 "저는 넷 상인..." 포함)
- 대사 중 찍히는 이름 때문에 창을 넘던 13건 수정
- 번역된 대사 전부를 선택지 커서 칸·실제 이름 폭까지 넣어 검사하고,
  창을 넘으면 빌드를 멈춤

## 남은 것

- **전투 결과 "딜리트 타임 / 버스팅 레벨"**: 이것도 그림으로 확인했습니다
  (문자열 쪽은 이미 번역돼 있는데 화면은 그것을 읽지 않음). 결과 화면을
  에뮬레이터로 띄워 그림 위치를 찾아야 하는데, 튜토리얼 배틀은 결과 화면이
  없어 아직 못 띄웠습니다.
- **압축된 미번역 대사 아카이브 15개**를 새로 찾았습니다(주로 게시판 글로
  보임).
- 대사 중 이름 앞 띄어쓰기 누락 약 230건 (창은 넘지 않음).
- 대형 갭에 묻힌 꼬리 대사 2줄, 전체 완주 QA.

## 검증

정적 무결성 검사와 표 내용 검사를 통과했습니다. 아카이브 393개, 번역
엔트리 8,290개, 창 검사 위반 0건. 안내 그림은 빌드 산출물과 같은 함수로
정적 검사에서 다시 만들어 대조합니다.
