# EXE2 Rev 1 한국어 패치 V0.9.13 (시험용)

원본 일본판 Rev 1 ROM에 BPS 또는 xdelta를 적용하세요. 이전 패치 ROM에는
덧씌우지 마세요.

## 튜토리얼 배틀 정지 — 원인 확인 후 수정

**원인은 대사창을 넘치는 번역문이었습니다.** 아카이브 재배치나 압축과는
무관했습니다.

대사창은 가로 21칸, 세로 3줄입니다. 원본 일본어는 어느 페이지도 20칸을
넘지 않습니다. 그런데 번역문 `00/352` 8번 엔트리는

```
선택할 수 있는 칩이 늘었죠!            16칸
3장이 늘어난 건 3장을 버렸기 때문에、   22칸  ← 초과
이 배틀 중에는 계속 이대로 싸울 수 있어요. 25칸  ← 초과
```

였습니다. 글자를 그리는 쪽이 창에 배정된 칸을 넘어 계속 쓰고, 대사창이
닫히고 커스텀(칩 선택) 화면으로 돌아오는 순간 게임이 멈췄습니다.

실기(My Boy!)에서 확인했습니다. 그 엔트리의 글자 여섯 자만 지워 21칸 안에
들어오게 한 ROM — **다른 바이트는 전부 동일** — 으로 같은 상태에서 다시
재현하니 정지 지점을 그대로 지나갔습니다.

## 같은 부류를 전부 닫았습니다

빌드에 두 가지 결함이 있었습니다.

**첫째, 재조판 판정이 잘못돼 있었습니다.** 페이지 안에 원래부터 공백뿐인
칸이 하나라도 있으면 재조판 결과를 통째로 버리고 넘치는 원래 문장을
내보냈습니다. 원래 공백이던 칸은 그대로 둬도 되는데 말입니다. 이것만
고치니 19건 중 8건이 저절로 해결됐습니다.

**둘째, 못 맞추면 그냥 내보냈습니다.** 이제 창을 넘기는 페이지가 하나라도
있으면 **빌드가 멈춥니다.** 원본이 그 창 안에 들어가는 경우만 위반으로
셉니다 — 원본이 넘는 경우는 창 모델이 틀린 것이지 번역 문제가 아니기
때문입니다. 실제로 원본이 넘는 페이지는 한 건도 없었습니다.

게이트가 잡은 11건의 번역문을 창에 맞게 줄였습니다. 뜻은 유지했습니다.

| 아카이브 | 줄인 내용 |
|---|---|
| 00/352/8 | 튜토리얼 칩 설명 (정지 원인) |
| 00/404/17 | PET 설명 |
| 00/202/1 | 기폭 장치 대사 |
| 00/175/0 | 환풍기 프로그램 대사 |
| 00/11/42 | 케로 응원가 |

| 00/27/71, 00/147/192, 00/148/91, 00/148/190 | 각 한 줄씩 |

## V0.9.12 에서 이어지는 것

카탈로그 마지막 아카이브(`00/355`, 전투 결과 화면)의 후속 스크립트 보존이
들어 있습니다. 후속 스크립트 224개, 374,209바이트를 원본 그대로 유지합니다.

## 검증

정적 무결성 검사와 표 내용 검사를 통과했습니다. 창을 넘기는 페이지는
0건입니다.

**실기에서 확인한 것**: 정지 원인과 그 수정. `00/352` 8번 엔트리의 줄 폭이
실기로 확인한 ROM과 바이트 단위로 같은 것도 대조했습니다.

**아직 확인 안 한 것**: 이 빌드 자체로 튜토리얼을 통과하는 것. 나머지 10건의
줄인 대사가 화면에 어떻게 보이는지. 전체 게임 완주 QA.

게임 내 저장(.sav)은 이전 판과 호환됩니다. 다만 이전 빌드의 상태 저장
(.ss1/.ss2, .mss, .st0~.st3)은 옛 배치를 되살리므로 사용하지 마세요.
