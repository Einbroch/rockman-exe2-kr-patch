록맨 에그제 2 한글패치 V0.9 - MENUPTR 진단 빌드
================================================

이 패키지는 정식 배포판이 아닙니다.
My Boy!(안드로이드)에서 게임 중 START로 PET 메뉴를 부르면 멈추는 증상의
원인을 좁히기 위한 진단용 빌드입니다.


지금까지 배제된 것
------------------

- ROM 크기          : 16MB도 10MB도 똑같이 멈춤 (TRIM10M 빌드로 확인)
- 8MB 위 데이터 읽기: 한글 대사가 정상 출력되므로 정상 동작
- 8MB 위 코드 실행  : 한글 대사가 F9 FC 훅 경로를 타므로 정상 동작
- 포인터 정렬       : 재배치 577개 중 574개가 4바이트 정렬, 원본과 동일

남은 차이는 "메뉴 리소스를 옮기는 방식"입니다. 대사는 CPU가 바이트 단위로
읽지만 메뉴 리소스는 보통 BIOS의 LZ77 전개(SWI)나 DMA로 옮깁니다.
My Boy!는 BIOS를 직접 쓰지 않고 흉내내므로 이 경로만 다르게 깨질 수 있습니다.


무엇이 다른가
-------------

메뉴가 실제로 읽는 것으로 확인된 포인터 두 개만 원래 값으로 되돌렸습니다.

  0x007370 : 0x0890061C -> 0x08797128
  0x0251E8 : 0x08900F00 -> 0x087D98D4

되돌린 목적지는 패치가 한 번도 건드리지 않은 원본 데이터라 그대로 살아
있습니다. 이 두 개만 빼면 나머지 575개 포인터와 코드 훅 3개는 V0.9와
완전히 같습니다. 즉 메뉴만 8MB 아래를 읽게 되고 대사는 그대로 한글입니다.


적용 방법 (Windows)
-------------------

1. 이 ZIP을 새 폴더에 완전히 압축 해제합니다.
2. 본인이 보유한 깨끗한 일본판 Rev 1 ROM
   `Battle Network Rockman EXE 2 (Japan) (Rev 1).gba`
   를 `APPLY_PATCH.cmd` 위로 끌어다 놓습니다.
3. `SUCCESS`가 표시되면 같은 폴더에
   `Rockman_EXE2_Rev1_KR_V0.9_MENUPTR_TEST.gba` 가 생성됩니다.
4. 그 ROM을 폰에 넣고 My Boy!에서 새로 부팅합니다.
5. 게임을 진행해 필드에서 움직일 수 있게 되면 START를 눌러 봅니다.


결과 해석
---------

- 메뉴가 열린다
  → 원인이 이 두 포인터가 가리키는 확장 구간 접근으로 확정됩니다.
    전개 경로(LZ77/DMA)를 파고들어 정식 수정안을 만들 수 있습니다.

- 여전히 멈춘다
  → 메뉴가 읽는 데이터가 원인이 아닙니다.
    에뮬레이터 쪽 요인(동적 리컴파일러, HLE BIOS)으로 범위를 옮깁니다.

어느 쪽이든 결과를 알려주시면 다음 단계를 잡습니다.


함께 시도해 볼 것 (ROM 교체 없이)
---------------------------------

My Boy! 설정에서 아래를 바꿔 V0.9 원래 빌드로 다시 시험해 보셔도
같은 갈림길을 확인할 수 있습니다.

  - 동적 리컴파일러(dynamic recompiler / fast mode) 끄기
  - 실제 GBA BIOS 파일을 지정해서 HLE 대신 사용하기

둘 중 하나로 메뉴가 열린다면 원인은 ROM이 아니라 My Boy!의 실행 방식입니다.


주의
----

이 빌드는 콜드부팅 스모크 테스트만 통과한 진단용입니다.
전체 게임 QA를 다시 돌린 것이 아니므로 본편 진행용으로 쓰지 마세요.
다른 빌드에서 만든 .ss1 / .ss2 상태 저장은 불러오지 마세요.
기존 .sav 배터리 세이브는 먼저 백업하세요.

원본 ROM과 패치된 ROM은 이 패키지에 들어 있지 않습니다.
