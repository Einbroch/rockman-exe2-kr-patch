록맨 에그제 2 한글패치 V0.9 - TRIM10M 진단 빌드
================================================

이 패키지는 정식 배포판이 아닙니다.
My Boy!(안드로이드)에서 START 메뉴 호출 시 게임이 멈추는 증상의
원인이 "ROM 크기"인지 가리기 위한 진단용 빌드입니다.


무엇이 다른가
-------------

내용은 V0.9와 완전히 같습니다. 번역, 폰트, 포인터, 코드 훅 어느 것도
바뀌지 않았습니다. 달라진 것은 ROM 뒤쪽에 붙어 있던 의미 없는 0xFF
패딩 6,291,456바이트를 잘라낸 것뿐이며, 그 결과 ROM 크기가
16,777,216바이트에서 10,485,760바이트로 줄어듭니다.

실제 데이터는 0x906049에서 끝나므로 잘린 구간에는 게임이 쓰는 바이트가
하나도 없습니다. 빌드 과정에서 잘리는 구간이 전부 0xFF인지 검사하며,
아니면 빌드가 실패합니다.


적용 방법 (Windows)
-------------------

1. 이 ZIP을 새 폴더에 완전히 압축 해제합니다.
2. 본인이 보유한 깨끗한 일본판 Rev 1 ROM
   `Battle Network Rockman EXE 2 (Japan) (Rev 1).gba`
   를 `APPLY_PATCH.cmd` 위로 끌어다 놓습니다.
3. `SUCCESS`가 표시되면 같은 폴더에
   `Rockman_EXE2_Rev1_KR_V0.9_TRIM10M_TEST.gba` 가 생성됩니다.
4. 그 ROM을 폰에 넣고 My Boy!에서 새로 부팅한 뒤 START 메뉴를 눌러 봅니다.

적용기는 원본 ROM의 크기와 SHA-256을 먼저 검사하고, 패치 파일과
Floating IPS 실행 파일의 해시도 확인합니다. 결과 ROM의 해시가 기대값과
다르면 결과물을 내놓지 않습니다. 기존 파일은 덮어쓰지 않습니다.


결과 해석
---------

- 메뉴가 정상적으로 열린다
  → 원인은 ROM 크기(16MB)입니다. 이 방식이 그대로 정식 수정안이 됩니다.

- 여전히 멈춘다
  → 원인은 크기가 아닙니다. 8MB 위 영역 접근 등 다른 요인을 봐야 합니다.

어느 쪽이든 결과를 알려주시면 다음 단계를 잡습니다.


주의
----

이 빌드는 콜드부팅 스모크 테스트만 통과한 진단용입니다.
전체 게임 QA를 다시 돌린 것이 아니므로 본편 진행용으로 쓰지 마세요.
다른 빌드에서 만든 .ss1 / .ss2 상태 저장은 불러오지 마세요.
기존 .sav 배터리 세이브는 먼저 백업하세요.

원본 ROM과 패치된 ROM은 이 패키지에 들어 있지 않습니다.
