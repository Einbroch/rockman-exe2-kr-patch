록맨 에그제 2 한글패치 V0.9 - MENU362MOVE 진단 빌드
====================================================

이 패키지는 정식 배포판이 아닙니다.


지금까지의 결과
---------------

  포인터 2개 되돌림 (00/352 + 00/362)  →  메뉴 정상
  00/352 만 되돌림                     →  메뉴 멈춤
  00/362 만 되돌림                     →  메뉴 정상

원인은 아카이브 00/362 하나로 확정됐습니다.
이제 00/362 의 무엇이 문제인지를 가릅니다.


00/362 가 재배치되며 바뀐 것 세 가지
------------------------------------

  1. 주소 : 0x7D98D4 (8MB 아래) -> 0x900F00 (8MB 위)
  2. 크기 : 0x7FE -> 0x1156 바이트 (2.16배)
  3. 바로 뒤에 오는 것
       원본     : 카탈로그 밖 꼬리 바이트 03 05 04 cd 9b a4 aa e7 00 00
       재배치본 : ff ff 패딩 + 다음 블록의 오프셋 표

한글 대사가 정상 출력되므로 1(8MB 위 읽기)은 이미 배제됐습니다.
이번 빌드는 2와 3을 가릅니다.


무엇이 다른가
-------------

00/362 를 같은 내용, 같은 길이로 0x910000 에 그대로 옮겼습니다.
이 자리는 패치가 한 번도 건드리지 않은 0xFF 빈 공간이고, 빌드할 때
정말로 전부 0xFF 인지 검사합니다.

  0x0251E8 : 0x08900F00 -> 0x08910000

크기도 그대로, 여전히 8MB 위입니다. 달라지는 것은 단 하나,
아카이브 뒤에 다른 블록의 표 대신 0xFF 가 이어진다는 점뿐입니다.


결과 해석
---------

- 메뉴가 열린다
  → 게임이 00/362 의 끝을 넘어 읽고 있고, 그 뒤에 다른 블록의 표가
    붙어 있는 것이 원인입니다. 재배치 시 각 아카이브 뒤에 여유를
    두거나 꼬리를 함께 옮기는 것이 정식 수정이 됩니다.

- 여전히 멈춘다
  → 뒤에 오는 것이 아니라 크기(0x7FE -> 0x1156)가 원인입니다.
    엔진이 이 아카이브를 고정 크기 RAM 버퍼로 옮기는지 확인해야 하고,
    그렇다면 번역량을 줄이거나 버퍼를 키우는 쪽으로 방향이 바뀝니다.
