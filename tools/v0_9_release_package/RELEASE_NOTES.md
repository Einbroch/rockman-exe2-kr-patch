# 록맨 에그제 2 한글패치 V0.9

배포일: 2026-09-13  
상태: 프리릴리스 / 부분 QA

## 포함 내용

- 깨끗한 일본판 Rev 1 원본에서 재현되는 통합 한글 ROM 변경분
- 번역 엔트리 7,607개와 2,351글자 한글 폰트
- 381개 텍스트 아카이브 재배치와 574개 포인터 수정
- raw 후속 스크립트 158개 보존 및 확인된 후속 대사 2개 한글화
- PET 선택창 배치 수정
- 일반 대사 340개 줄바꿈 조정
- `Jumped to invalid address: 71683800` 진행 중단 원인 수정

## 검증 현황

- 정적·바이트 검증: `PASS (bench)`
- 음소거 Mesen 2 자연 입력: 226개 세그먼트, 531개 화면 증거
- 저장, 새 부팅 후 Continue, 대표 선택지, 대사 종료와 맵 이동 확인
- 테스트한 학교·집·동네·공원 경로에서 수정 후 충돌과 새 텍스트 넘침이 관찰되지 않음

## 알려진 제한사항

- 번역 문장은 아직 사람의 전체 최종 검수를 거치지 않은 초안입니다.
- 타이틀·일부 메뉴·저장 화면에는 일본어가 남아 있습니다.
- 물리 후속 스크립트 156개는 일본어 원문 보존 상태입니다.
- `00/357`의 95개 엔트리는 참조 경로 미해결로 적용되지 않았습니다.
- 특수 창·변수 삽입·일부 선택창과 보류된 레이아웃 사례는 추가 확인이 필요합니다.
- 전체 게임 완주 및 mGBA 전용 전체 자연 플레이 검증은 완료되지 않았습니다.
- 따라서 V0.9는 완성판이나 최종 릴리스가 아닙니다.

## 도구와 폰트

- EXE1 한글판 픽셀 폰트는 프로젝트 사용자가 재사용 허가를 받았다고 확인한 범위에서 사용했습니다.
- 일부 글자는 굴림 대체 글리프를 사용합니다.
- Floating IPS v198 실행 파일, GPL 라이선스와 해당 태그의 소스를 동봉합니다.
