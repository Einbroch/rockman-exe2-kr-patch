# EXE2 Rev 1 한국어 패치 V0.9.25 (시험용)

원본 일본판 Rev 1 ROM에 동봉된 BPS 패치를 적용하세요(`APPLY_PATCH.cmd` 또는
동봉된 flips). 이전 패치 ROM에는 덧씌우지 마세요.

## 고친 것: 버스터 강화 때 멈춤

V0.9.4부터 V0.9.24까지 모든 판에서, 록맨 상태 화면에서 버스터 UP으로
ATTACK·RAPID·CHARGE를 강화하려 하면 "내비 칩은 전부 8장까지 넣을 수 없어"라는
엉뚱한 대사가 나온 뒤 게임이 멈췄습니다.

원인은 확인 문구 "(バスターUP のこり [개수] コ)"에 있었습니다. 개수를 찍는
명령에는 버스터 UP의 아이템 번호 0x61이 인수로 들어 있는데, 이 바이트는
글자 "D"로도 읽힙니다. 그래서 번역 치환 "Dコ" → "개"가 인수까지 바꿔
버렸고, 뒤따르는 바이트가 "게임을 저장하고 18번 문구로 이동"하는 명령으로
읽혔습니다.

**이 결함 때문에 멈추기 직전에 게임이 한 번 자동 저장됩니다.** 저장 시점은
강화하기 직전이라 버스터 UP은 쓰이지 않은 채 남아 있습니다. V0.9.25에서 그
세이브를 불러 정상적으로 강화할 수 있는 것을 에뮬레이터에서 확인했습니다.

상태·폴더·메일·저장·통신 메뉴가 함께 쓰는 공용 UI 표 전체를 고쳤습니다.
이제 문구를 명령과 글자로 먼저 나눈 뒤 글자만 번역합니다. 원문에서 비어
있던 칸도 원문대로 비워 둡니다.

## 같이 다듬은 문구

- 강화 확인: "록버스터의 공격력을 올릴까? / (남은 버스터 UP 3개)"
- 조사 오류 12곳. 예:
  - 내비 칩가 너무 많아 → 내비 칩이 너무 많아
  - 레귤러 용량가 부족해서 → 레귤러 용량이 부족해서
  - 노멀 스타일로 로 돌아왔어 → 노멀 스타일로 돌아왔어
  - 「…」을 을 사용할까? → 「…」 사용할까?
- 띄어쓰기: "내비 칩은 전부5장까지" → "전부 5장까지"

## 검증

정적 무결성 검사와 표 내용 검사를 통과했습니다. 표 내용 검사에 새 항목을
넣었습니다. 번역된 표를 TextPet으로 다시 읽어, 모든 스크립트의 명령과
인수가 원문과 똑같은지 비교합니다(공용 UI 표 109개와 칩 이름·설명 표 765개
모두 일치). 이 검사는 V0.9.24에서는 실패합니다.
V0.9.24와 비교해 바뀐 바이트는 공용 UI 표 영역뿐입니다.

에뮬레이터(Mesen)에서 다음을 확인했고, 모두 멈추지 않았습니다.

- 버스터 UP 3개로 ATTACK 확인 문구 → 예 → "공격력이 올랐어!" → 메뉴로 복귀
- RAPID 확인 문구(남은 2개)에서 B로 취소
- CHARGE 강화, 마지막 1개를 쓴 뒤 상태 화면으로 복귀
- 결함 때 자동 저장된 세이브를 불러 강화
- 강화 과정에서 세이브 파일이 바뀌지 않음
