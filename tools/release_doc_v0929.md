# EXE2 Rev 1 한국어 패치 V0.9.29 (시험용)

원본 일본판 Rev 1 ROM에 동봉된 BPS 패치를 적용하세요(`APPLY_PATCH.cmd` 또는
동봉된 flips). 이전 패치 ROM에는 덧씌우지 마세요.

## 바뀐 것: 한글 타이틀 로고

타이틀 화면의 로고를 한글로 바꿨습니다.

- 큰 글씨 `ロックマンエグゼ` → `록맨 에그제`: 한국판 박스 그림의 글자 모양을 따르고,
  원본 로고의 색 그라데이션·검정 외곽선·흰 테두리로 칠했습니다.
- 작은 글씨 `バトルネットワーク >>` → `배틀 네트워크 >>`: 이 크기에 맞춰 굵은 픽셀
  글자를 직접 그렸습니다.
- `2`, `TM`, 고리, 격자 배경은 원본 그대로입니다.

대사와 메뉴는 V0.9.28과 같습니다. 게임 내 저장(`.sav`)은 그대로 쓸 수 있습니다.

## 검증

- 정적 무결성 검사와 표 내용 검사를 통과했습니다. 정적 검사에 항목을 새로 넣었습니다.
  게임 코드가 따라가는 주소로 타이틀 그림을 다시 그려 보고, 기록된 그림과 같은지 확인합니다.
- V0.9.28과 비교해 바뀐 곳은 타이틀 그림 데이터와 그것을 가리키는 주소 세 곳뿐입니다.
- 에뮬레이터(Mesen)에서 세이브 없이 부팅해 타이틀 화면과 Start 뒤 메뉴(`처음부터`)가
  정상으로 나오는 것을 확인했습니다.
