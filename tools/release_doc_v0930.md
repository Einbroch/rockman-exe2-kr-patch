# EXE2 Rev 1 한국어 패치 V0.9.30 (시험용)

원본 일본판 Rev 1 ROM에 동봉된 BPS 패치를 적용하세요(`APPLY_PATCH.cmd` 또는
동봉된 flips). 이전 패치 ROM에는 덧씌우지 마세요.

## 고친 것: 타이틀의 "배틀 네트워크"가 "네트위크"로 보임

V0.9.29의 한글 타이틀 로고에서 작은 글씨 `배틀 네트워크`의 `워`가 `위`처럼 보였습니다.
`워`와 `위`를 가르는 ㅓ의 짧은 가로획이 1픽셀뿐이라 눈에 띄지 않았기 때문입니다.

- `워`: ㅓ의 가로획을 3픽셀로 늘려 글자 한가운데에 두었습니다.
- 얇은 가로획을 옅은 분홍 대신 진한 분홍으로 칠해 더 잘 보이게 했습니다.
- `네`의 ㅔ 가로획도 조금 키웠습니다.

큰 글씨 `록맨 에그제`와 대사·메뉴는 V0.9.29와 같습니다. 게임 내 저장(`.sav`)은 그대로 쓸 수
있습니다.

## 검증

- 정적 무결성 검사와 표 내용 검사를 통과했습니다. 게임 코드가 따라가는 주소로 타이틀 그림을
  다시 그려 보고, 기록된 그림과 같은지도 확인합니다.
- V0.9.29와 비교해 바뀐 것은 타이틀 그림의 작은 글씨 줄 안 픽셀 205개입니다.
- 에뮬레이터(Mesen)에서 세이브 없이 부팅해 타이틀 화면과 Start 뒤 메뉴(`처음부터`)가
  정상으로 나오는 것을 확인했습니다.
