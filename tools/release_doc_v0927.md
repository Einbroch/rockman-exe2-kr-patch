# EXE2 Rev 1 한국어 패치 V0.9.27 (시험용)

원본 일본판 Rev 1 ROM에 동봉된 BPS 패치를 적용하세요(`APPLY_PATCH.cmd` 또는
동봉된 flips). 이전 패치 ROM에는 덧씌우지 마세요.

## 고친 것: 사이토 스타일 표기

サイトスタイル(히카리 사이토의 이름에서 유래)을 이메일에서만 "사이트 스타일"로
적고 있었습니다. 스타일 이름표·설명과 같은 "사이토 스타일"로 맞췄습니다.

- 이메일 목록: 아빠 / 사이트 스타일 설명 → 사이토 스타일 설명
- 이메일 본문: "사이트 스타일은 / 록맨의 잠재 능력을 …" 등 3곳

## 검증

- 정적 무결성 검사와 표 내용 검사를 통과했습니다.
- V0.9.26과 비교해 바뀐 것은 이메일 목록 1개, 본문 1개뿐이고, 글자 차이는
  "사이트→사이토" 네 곳뿐입니다.
- 에뮬레이터(Mesen)에서 이메일 본문 글자를 대사창으로 띄워 확인했습니다.
  이메일 화면 자체와 목록은 빌드 결과를 풀어 확인했습니다.
