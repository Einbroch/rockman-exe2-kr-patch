# EXE2 Rev 1 한국어 패치 V0.9.7

원본 일본판 Rev 1 ROM에 BPS를 적용하세요. 이전 패치 ROM에는 덧씌우지 마세요.

## 이번 수정 — 타이틀 메뉴 한글화

타이틀 화면의 두 선택지를 한글로 바꿨습니다.

- 첫째 줄 → `처음부터`
- 둘째 줄 → `이어하기`

이 두 라벨은 글자가 아니라 스프라이트 그림입니다. 원문을 인코딩해 ROM 전체를
검색해도 나오지 않고, 메뉴 표시 전후로 타일은 그대로인 채 OAM만 바뀝니다.
그래서 텍스트 경로가 아니라 타일을 직접 다시 그렸습니다. 라벨당 80x16 픽셀
칸에 프로젝트의 마스터 한글 폰트를 얹었고, 색 구성은 원본을 따라 본체와
외곽선을 그대로 유지합니다.

해당 타일을 가리키는 포인터가 없고 ROM 안에 사본도 하나뿐이라, 재배치나
포인터 수정 없이 제자리 교체로 끝납니다.

## V0.9.6 에서 이어지는 것

전환 화살표의 글자가 전용 글리프로 그려집니다. 배낭 화살표는 `케이스`,
칩 폴더 화살표는 `데크` 이며, `메`·`라`·`러` 의 모음 오류도 함께 고쳐져
`라이브러리` 가 바르게 표시됩니다.

## 검증

정적 무결성과 표 내용 검사를 통과했습니다. V0.9.6 대비 바뀐 바이트는 862개로
전부 타이틀 라벨 두 블록 안에 있고, 그 밖의 번역 데이터와 코드는 그대로입니다.
타일 계산은 빌더와 검증기 양쪽에 연결되어 있어, 다시 빌드해도 마스터 폰트에서
같은 결과가 재현되는지 자동으로 대조합니다.

화면 확인은 음소거 Mesen 2 에서 사람이 직접 했습니다. 자동 회귀 테스트는 이
후보로 돌리지 않았으므로 통과를 주장하지 않습니다.

## 남은 것

Android My Boy! 기기 확인과 전체 게임 QA는 아직입니다.

이메일 본문은 여전히 일본어입니다. 원인은 규명했습니다. 해당 텍스트는 번역
파이프라인이 다루지 않는 아카이브에 있고, 그 아카이브는 주소를 코드가
계산하는 방식이라 재배치할 포인터가 없으며 뒤쪽에 여유 공간도 없습니다.
작업이 계속 진행 중입니다.

학교에서 나갈 때의 블랙아웃 보고는 아직 재현되지 않았습니다. 번역 문장은
사람의 전체 최종 검수를 거치지 않은 초안이며, 일부 화면에는 일본어가 남아
있습니다. 최종 배포판이 아닙니다.

ROM과 저장 파일은 포함하지 않습니다. 새 ROM을 콜드 부팅하고 게임 내 일반
저장(.sav)을 쓰세요. 이전 빌드의 상태 저장(.ss1/.ss2)은 옛 그래픽이 올라간
VRAM까지 되살리므로 사용하지 마세요.
