# EXE2 Rev 1 한국어 패치 V0.9.23 (시험용)

원본 일본판 Rev 1 ROM에 동봉된 BPS 패치를 적용하세요(`APPLY_PATCH.cmd` 또는
동봉된 flips). 이전 패치 ROM에는 덧씌우지 마세요.

## 게시판·남은 대사 아카이브 한글화

번역 목록에 없던 **압축 대사 아카이브 15개**를 찾아 번역했습니다(831건).
대사 표가 아니라 코드가 주소를 직접 들고 있어서 기존 추출 범위에서
빠져 있던 것들입니다.

| 내용 | 아카이브 | 건수 |
|---|---|---|
| 의뢰 게시판 목록·본문 | 0x07E85FC / 0x07E9970 | 18 / 117 |
| 배틀 정보 게시판 | 0x07E8838 / 0x07EA9C4 | 63 / 63 |
| 길거리 정보 게시판 | 0x07E8B44 / 0x07EBE0C | 47 / 63 |
| 바이러스 정보 게시판 | 0x07E8E3C / 0x07ED1A4 | 63 / 63 |
| 잡담 게시판 | 0x07E9134 / 0x07EE4F4 | 44 / 63 |
| 언더 비밀 게시판 | 0x07E9470 / 0x07EF494 | 32 / 63 |
| 언더 정보 게시판 | 0x07E9714 / 0x07F0220 | 32 / 62 |
| 야이토 집 맵 대사 | 0x074B590 | 19 |

- 게시판 목록은 원문처럼 작성자 칸(7칸 또는 10칸) 뒤에 제목이 오도록
  맞췄고, 한 줄 폭은 그 게시판 원문의 최장 폭을 넘지 않습니다.
- 본문은 원문과 같은 쪽 나눔을 지키고 한 줄 20칸 이내로 썼습니다.
- 의뢰 게시판에서 의뢰를 수행 중일 때 나오는 안내("이 의뢰는 현재
  수행 중입니다")는 표 바깥에 붙은 스크립트라 따로 번역해 넣었습니다.
- 칩·바이러스·지명 표기는 기존 번역(칩 이름표, 대사)과 맞췄습니다.

## 검증

정적 무결성 검사와 표 내용 검사를 통과했습니다. V0.9.22와 비교해 기존
아카이브의 내용은 바뀌지 않았고, 새 아카이브 15개와 그 포인터 17곳만
추가됐습니다.

에뮬레이터(Mesen)에서 게시판 0~6번을 모두 열어 목록과 본문(가장 긴 줄,
칩 이름이 들어간 글, 의뢰 수행 중 안내 포함)이 창 안에 제대로 나오는 것을
확인했습니다. 야이토 집 대사는 빌드 검사로만 확인했습니다.
