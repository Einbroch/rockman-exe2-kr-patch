# EXE2 Rev 1 한국어 패치 V0.9.17 (시험용)

원본 일본판 Rev 1 ROM에 BPS 또는 xdelta를 적용하세요. 이전 패치 ROM에는
덧씌우지 마세요.

## 카탈로그 밖 아카이브를 처음으로 번역했습니다

번역 카탈로그는 특정 포인터 표에서 만들어졌습니다. 코드가 **리터럴로 직접
가리키는** 아카이브는 거기 들어가지 않아, 아무리 번역해도 화면에 일본어로
남았습니다. 전투 중 "1턴만 기다려", 도망 판정 대사가 그것이었습니다.

### 찾는 방법

모양으로는 못 찾습니다. u16 경계표는 그냥 오름차순 숫자라, 알려진 224개
raw 아카이브와 우연 후보를 가를 지표가 없었습니다.

**쓸 수 있는 기준은 참조입니다.** 정렬된 u32 리터럴이 그 주소를 가리키고,
그 자리에 `values[0] == 표 크기` 인 경계표가 있으면 아카이브입니다. 이
기준으로 **카탈로그 383개를 하나도 빠짐없이 재발견**하는 것이 기준 자체의
검증입니다. 빌드가 아카이브를 옮길 때 하는 일이 바로 그 리터럴을 전부 다시
쓰는 것이라, 이 기준으로 찾은 것은 곧 빌드가 다룰 수 있는 것입니다.

`tools/scan_text_archives.py` 가 미카탈로그 아카이브 37개를 찾아 36개를
해독했습니다(`analysis/uncatalogued_archive_tpl/`).

### 넣는 방법

`tools/uncatalogued_archive_batch.py` 가 빌드가 이미 검사하는 보호 배치
형태로 바꿉니다. 문제는 draft 문법(`/`, `//`, `[tag]`)을 손으로 쓰면
추측이 된다는 것이어서, **원문에서 골격을 뽑아 냅니다** — 각 엔트리마다
원본 스크립트를 그대로 되살리는 draft 를 만들고, **진짜 변환기를 돌려 원본
블록과 같은지 확인**합니다. 왕복이 안 되는 엔트리는 추측하지 않고 보고만
합니다. 번역은 구조가 이미 검증된 골격 안의 글자만 바꾸는 일이 됩니다.

### 이번에 들어간 것

`0x0731310` (44 엔트리, 2,343바이트, 코드 7곳에서 참조):

- 전투 중 "록맨! 추가 칩 데이터 보낼 테니 한 턴만 기다려!"
- 도망 성공·실패 대사
- 통신 에러
- **스타일 레벨업 문구 32종** (일렉/히트/아쿠아/우드 × 거츠/커스텀/브라더/실드 × 2·3레벨)

35개 엔트리를 번역했습니다. 아카이브는 확장 영역으로 옮겨졌고 참조 7곳이
모두 새 주소로 다시 쓰였습니다.

## 남은 것

- **선택창 엔트리**(`0x0731310` 2번, "여기는 도망치는 게 좋을까?") — 골격이
  왕복하지 않습니다. 선택창은 질문과 선택지가 한 줄에 겹치는 별도 부류라
  같이 다뤄야 합니다.
- 미카탈로그 아카이브 7개가 더 있습니다: 스타일 체인지 이벤트(4벌), 싱크로율
  200%, 전자파 제어, 층 선택, 흡혈, 게시판 — 일본어 약 7,600자.
- **칩 이름 2번 뱅크(`0x0729B3C`)와 칩 설명 2·3·4번이 처리에서 빠져
  있습니다.** 참조 수가 이미 처리된 1번 뱅크와 같은데(14곳) 포인터가 하나도
  다시 쓰이지 않았습니다. 죽은 사본인지 실기 확인이 필요합니다.
- 전체 게임 완주 QA 미완료.
