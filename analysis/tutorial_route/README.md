# 튜토리얼 배틀까지 가는 길 (Mesen, 스크립트 입력)

`pre_tutorial_battery.sav` 는 기기(My Boy!)에서 받아온 게임 내 저장이다.
빌드 배치와 무관하므로 어떤 후보 ROM에서도 쓸 수 있다. Mesen 의 `Saves/`
폴더에 후보 ROM 이름으로 복사한 뒤 콜드 부트한다.

`tools/probe_mail_screen_freeze.py --actions` 로 넣은 입력 순서:

1. `none:1:400, start:10:50, a:10:50, start:10:50, a:10:50, b:10:50, b:10:50, b:10:50`
   - 인트로 데모를 건너뛰고 저장을 불러온다. ACDC 마을 필드에서 시작한다.
2. `up:150:20, right:150:20, up:150:20, left:150:20, down:150:20, left:150:20,`
   `up:250:20, right:250:20, down:250:20`
   - 넷토네 집에 들어간다. "엄마에게 다녀왔다고 해야지" 가 뜬다.
3. 부엌으로 가서 어머니에게 말을 건다(A). 대화는 순환하므로 끝내고 물러난다.
4. `up`/`left` 로 2층 방에 올라간다. 어머니가 따라와 "생각났다!" 장면이 나온다.
5. A 를 40회 눌러 장면을 끝내면 `Rボタンで パソコンに` 안내가 뜬다.
6. `r:10:60` 으로 플러그인. 넷 안에서 A 를 눌러 프로그램과 대화하면
   "숙제 프로그램" 배틀이 시작된다.

칩 선택 커서: 1행 5칸 + OK(오른쪽), ADD(OK 아래). **1번 칩에서 right 5번이면
OK**, right 6번이면 다시 1번 칩으로 돌아온다. OK 에서 down 이 ADD 다.
위/아래는 2행이 비어 있으면 움직이지 않는다.

`*_v0911.mss` 는 v0.9.11 ROM 전용이다. 다른 빌드는 아카이브 배치가 달라
불러오면 첫 프레임부터 멈춘다.
