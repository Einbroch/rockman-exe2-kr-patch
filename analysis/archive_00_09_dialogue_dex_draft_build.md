## 이번 확장

TextPet 전체 추출에서 엔트리 0이 직접 점프하는 엔트리 1을 추가했다. 덱카오는
넷토에게 방과 후 모두 함께 인터넷하자고 말한 뒤 선생님이 온다고 알린다.

- 페이지 1: `오, 넷토!`
- 페이지 2: `오늘 학교 끝나면` / `다 같이 인터넷하자!`
- 페이지 3: `자세한 건 나중에 말해 줄 테니까` / `기대하고 있으라고!`
- 페이지 4: `...엇` / 30프레임 대기 / `선생님이 오신다!`
- 현재 번역 엔트리: 0, 1, 2, 3, 4, 13 — 6개
- 미번역 보존 엔트리: 248개
- 필요한 한글 글리프: 90자
- 코드페이지 전체 매핑: 96자, 남은 후보 슬롯 160개

말투와 이름 표기는 독립 번역 검토와 사람 승인이 필요하다.

## 제어 코드 보존

엔트리 1의 교체 범위에는 페이지 입력·지우기 `EB E9`, 줄바꿈 `E8`, 마지막
문장 중간의 `EA 01 1E 00` (`waitSkip`, 30프레임), 마지막 입력 대기 `EB`가
들어 있다. 빌더는 검증된 인라인 명령만 구조적으로 허용하고 `EA`의 낮은 값
매개변수까지 원문과 같은지 검사하도록 보강했다. 창 닫기·플래그 514 설정·종료
`F1 01 F2 00 02 02 E7`은 교체 범위 밖에서 바이트 그대로 보존한다.

해제본과 비교했다.

수행했다.
