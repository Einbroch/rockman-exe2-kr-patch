일본판 Rev 1 전용 한글 차분 패치 **V0.9.5 UiFit**입니다. 프리릴리스이며 완성판은 아닙니다.

원본 ROM, 패치된 ROM, 저장 파일은 포함하지 않습니다. 본인이 보유한 패치 전 원본 ROM이 필요합니다.

## V0.9.4에서 달라진 점

- 주황색 전환 화살표의 **메모 / 라이브러리**를 전용 7×6 픽셀 글자로 교체했습니다. 원래 P.A와 같은 높이·기준선을 사용하고, 아래쪽 여백을 확보했습니다.
- 화살표 안에 남아 있던 일본어 글자와 그림자의 점을 제거했습니다.
- 저장 화면의 마지막 ‘리’가 빠지던 문제를 수정했습니다. 고정된 8글자 폭에 맞춰 이 항목만 **데이터라이브러리**로 붙여 써 전체 음절을 표시합니다.
- 기존 메뉴·대사 번역과 일반 폰트는 유지했습니다. 이번 표시 수정으로 CPU 코드, VRAM 배치, 일반 저장 형식을 변경하지 않았습니다.

## 설치

BPS와 xdelta는 같은 결과 ROM을 만듭니다. **둘 중 하나만** 패치 전 원본에 적용하세요. 이전 한글패치 ROM에 덧씌우거나 두 형식을 연속 적용하지 마세요.

### BPS — Windows 적용기 동봉

1. `EXE2_Rev1_KR_V0.9.5_UiFit.zip`을 새 폴더에 완전히 압축 해제합니다.
2. 원본 ROM을 `APPLY_PATCH.cmd` 위로 끌어다 놓습니다.
3. 성공 메시지와 함께 생성된 새 ROM을 사용합니다.

ZIP에는 BPS 패치, 적용기, 안내문, Floating IPS v198 실행 파일·라이선스·소스가 들어 있습니다. 도구 소스의 성능 테스트 자료까지 포함되어 ZIP 크기는 약 42.6 MiB입니다.

### xdelta

`EXE2_Rev1_KR_V0.9.5_UiFit.xdelta`를 xdelta3 호환 패처로 원본 ROM에 적용합니다. 패처는 별도로 준비해야 합니다.

적용 후 에뮬레이터에서 새 ROM을 완전히 다시 실행하세요. 이전 ROM에서 만든 상태 저장(`.ss1`, `.ss2` 등)은 사용하지 말고, 필요한 경우 새 ROM 파일명에 맞춘 게임 내 일반 저장(`.sav`)으로 이어서 하세요.

## 검증 범위와 제한

- BPS와 xdelta 모두 깨끗한 원본에 재적용한 전체 바이트가 검증 ROM과 일치합니다.
- xdelta 반복 생성 결과가 동일하며, 테스트한 잘못된 입력은 디코더가 거부했습니다.
- 음소거 Mesen에서 메뉴·화면 전환·저장·새 프로세스 이어하기를 포함한 15개 구간을 확인했습니다.
- 전후 확대 화면 3장과 실제 VRAM을 대조해 화살표의 전체 글자·여백 및 저장 항목 마지막 ‘리’를 확인했습니다.
- **Android My Boy! 기기 직접 검증과 전체 게임 완주 QA는 아직 완료되지 않았습니다.**
- 번역은 전체 사람 검수가 끝나지 않은 초안입니다. 기존 미적용 번역 95개와 미번역 물리 후속 대사, 일부 영어·일본어 표기가 남아 있습니다.
