## 이번 수정: 대사 속 띄어쓰기·줄바꿈

대사 중간에 이름을 찍거나 잠깐 멈추는 자리에서, 번역문에 적어 둔 공백이나 줄바꿈이
빌드 과정에서 지워지고 있었습니다. 대사 194개를 고쳤습니다.

### 이름 앞뒤 (37곳)

- 정말이네、서브 라이선스를 → 정말이네、 서브 라이선스를
- 오~서브 라이선스시험을 보고 있구나. → 오~ 서브 라이선스 / 시험을 보고 있구나.
- 열려면전뇌 열쇠가 필요하다! → 열려면 / 전뇌 열쇠가 필요하다!

### 잠깐 멈추는 자리 (186곳)

- 분하지만...자・극・적・이・야. → 분하지만... 자・극・적・이・야.
- 하지만!넷토를 → 하지만! 넷토를
- 뉴스는 살아 있어!...라니、 → 뉴스는 살아 있어! ...라니、

점을 하나씩 찍으며 멈추는 말줄임("・・・")과 말 더듬기("뭐・뭐・뭐라고")는 원문처럼
붙여 둡니다. 멈추는 자리에서 줄을 바꿀지는 원문을 따릅니다.

### 원문이 줄바꿈만 두는 자리 (10곳)

- 장작이 필요하다고~? 뚝딱뚝딱뚝딱뚝딱! → 장작이 필요하다고~? / 뚝딱뚝딱 뚝딱뚝딱! / 이얏~!!

### 함께 다듬은 대사

- 라이선스 시험관: "클리어 보상은 [이름]입니다."를 원문처럼 3줄에 맞춤
- "아! 넷토! 나 또 / 칼을 두고 왔나 봐!" (원문 줄바꿈 위치)
- "이걸로 못 해내면 남자가 아니지." (창에 들어가도록 줄임)
