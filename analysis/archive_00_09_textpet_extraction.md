# 아카이브 00/09 전체 가역 추출

## 결과

Rev 1 ROM의 LZ77 아카이브 00/09를 TextPet 형식으로 전체 추출하고 다시
바이너리로 조립했다. 재조립 결과는 원래 해제 데이터와 6,072바이트 전부
동일하며 SHA-256도
`92852d9c874fe0d5293d0c47920f2b987ff1de9fef232fa24489b7700a670667`로 같다.

- 전체 엔트리: 254개
- 내용이 있는 엔트리: 71개
- 빈 엔트리: 183개
- 추출 스크립트 ID와 비어 있지 않은 테이블 엔트리 대응: 일치
- 추출→재조립 차이: 0바이트
- 판정: 통과

기계 판독 결과는 `analysis/archive_00_09_textpet_full_roundtrip.json`, 반복
실행 도구는 `tools/extract_archive_00_09_textpet.py`다.

## 외부 구성요소

TextPet v1.0.0 실행 파일과 커밋
`6c6d70561290b42d8261f6d76b03051d534c7032`의 EXE2 UTF-8 테이블 및 명령
데이터베이스를 사용했다. 실행 파일·테이블·명령 데이터베이스의 해시는
라운드트립 보고서에 고정돼 있다.

## 배포 경계

`analysis/archive_00_09_textpet_full.tpl`은 ROM에서 추출한 일본어 원문을
포함하는 로컬 분석 자료다. 패치 배포물에 포함할 수 없으며, 공개 산출물은
지원 원본을 사용자가 직접 준비한 뒤 차분 패치와 재현 도구만으로 구성해야
한다.
