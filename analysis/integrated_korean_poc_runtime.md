# Rev 1 통합 한글 PoC 빌드·런타임 검증

## 재현 가능한 빌드

`tools/build_integrated_korean_poc.py`는 수정하지 않은 일본판 Rev 1 ROM에서
다음 두 단계를 순서대로 실행한다.

1. `pc-jap-map-0023`을 `0x7FF970`으로 재배치하고 비어 있지 않은 9개
   엔트리에 `가나다`를 삽입한다.
2. LZ77 아카이브 00/09를 16 MiB 확장 영역 `0x800000`으로 재배치하고,
   상태 관찰로 확인한 엔트리 2와 13에 `가나다`를 삽입한다.

최종 ROM SHA-256은
`25a41bfb0c6aabd3c2bd30c07c06f157b3d77dc0a1ab5fed3f9867b309357509`이다.
이는 기존에 Mesen2/emucap으로 실행 검증한 확장 PoC와 바이트 단위로 같다.
원본 8 MiB 안에서 달라진 701바이트는 활성 블록 재배치, 포인터 리터럴,
세 폰트 레코드, 아카이브 포인터 워드의 선언 범위에만 존재한다.

## 런타임 아카이브 적재

첫 새 게임 로드에서 `0x08800000` 읽기 브레이크포인트가 적중했다. 그 뒤
덤프한 EWRAM의 `0x02038800`부터 6,084바이트는 확장 ROM의 LZ77 스트림을
풀어 얻은 결과와 SHA-256
`92ec323060e496f7f6e8aaffd1665d1e6cd024b9cf526f7cdff3496d22d2692e`로
일치하며, 서로 다른 바이트 수는 0이다.

검증 스크립트는 오프셋 테이블을 254개 엔트리로 해석하고 다음도 확인한다.

- 엔트리 2: `0x028A..0x02A9`, 31바이트, 마커 상대 위치 20
- 엔트리 13: `0x0583..0x0625`, 162바이트, 마커 상대 위치 43

일반 플레이에서 교실 책상 대화를 열었을 때 렌더러의 source block base는
`0x02038800`이었고, current/end 포인터는 같은 재배치 풀의 엔트리 228
경계 `0x1538..0x156B`에 대응했다. 따라서 성장한 앞쪽 엔트리 뒤의 높은
번호 엔트리까지 정상 경로로 도달함을 확인했다.

## 엔트리 2·13 직접 렌더링

원본 SS1/SS2는 렌더러 커서가 각각 엔트리 2의 상대 위치 20과 엔트리
13의 상대 위치 43에 멈춘 상태다. 두 상태의 EWRAM 아카이브 풀을 통합
ROM에서 풀어 얻은 정확한 6,084바이트로 교체하고, 엔트리 13은 앞쪽
성장분 6바이트만큼 renderer current/start 포인터를 함께 이동했다.

mGBA 0.10.5에서 통합 ROM과 이 상태를 로드한 결과 두 화면 모두 실제
게임 렌더러로 `가나다`를 표시했다.

- 엔트리 2 화면: `analysis/emucap/archive_entry_2_hangul_render.png`
- 엔트리 13 화면: `analysis/emucap/archive_entry_13_hangul_render.png`

## 증거 경계

이전의 임의 렌더러 포인터 변경 시험은 필요한 제어 상태를 함께
초기화하지 않아 화면 갱신에 실패했으므로 표시 증거로 세지 않는다.
새 SS1/SS2 시험은 상태 개입을 명시적으로 기록한 렌더러 소비 증거다.
정상 플레이가 확장 ROM에서 같은 아카이브를 로드한다는 증거는 Mesen2의
읽기 브레이크포인트와 EWRAM 덤프가 별도로 담당한다. 두 증거를 결합하면
정확한 ROM 적재와 두 수정 엔트리의 실제 글리프 표시를 모두 확인하지만,
임의의 254개 엔트리 전체나 생산용 코드페이지 안전성을 증명하지는 않는다.

기계 검증 결과는
`analysis/emucap/expanded_archive_runtime_verification.json`, 원본 메모리
덤프는 `analysis/emucap/expanded_archive_after_first_load/`에 보관한다.

## 후속 번역 초안 빌드

두 마커 위치를 실제 한국어 초안으로 교체한 후속 빌드와 화면 검증은
`analysis/archive_00_09_translation_draft_build.md`에 별도로 기록한다.
마커 ROM의 정상 적재 증거와 번역 ROM의 상태 개입 렌더 증거를 같은
실행 증거로 합치지 않는다.
