## 이번 수정: 타이틀의 "배틀 네트워크"가 "네트위크"로 보임

![타이틀 작은 글씨 비교: 왼쪽 V0.9.29, 오른쪽 V0.9.30](https://raw.githubusercontent.com/Einbroch/rockman-exe2-kr-patch/v0.9.30/analysis/exe2_rev1_kr_v0_9_30_title_wo_before_after.png)

V0.9.29의 한글 타이틀 로고에서 작은 글씨 `배틀 네트워크`의 `워`가 `위`처럼 보였습니다.
`워`와 `위`를 가르는 ㅓ의 짧은 가로획이 1픽셀뿐이라 눈에 띄지 않았기 때문입니다.

- `워`: ㅓ의 가로획을 3픽셀로 늘려 글자 한가운데에 두었습니다.
- 얇은 가로획을 옅은 분홍 대신 진한 분홍으로 칠해 더 잘 보이게 했습니다.
- `네`의 ㅔ 가로획도 조금 키웠습니다.

큰 글씨 `록맨 에그제`와 대사·메뉴는 V0.9.29와 같습니다. 게임 내 저장(`.sav`)은 그대로 쓸 수
있습니다.

## ⚠ V0.9.27 이하를 쓰고 계시면 이 판으로 바꾸세요

- **V0.9.9, V0.9.24 ~ V0.9.27:** 마더컴퓨터 방(체인지.bat 에피소드)에서 NPC에게 말을 걸어도
  반응이 없고 플러그인도 되지 않아 진행할 수 없습니다(V0.9.28에서 수정).
- **V0.9.4 ~ V0.9.24:** 록맨 상태 화면에서 버스터 UP으로 강화하면 게임이 멈춥니다(V0.9.25에서 수정).
